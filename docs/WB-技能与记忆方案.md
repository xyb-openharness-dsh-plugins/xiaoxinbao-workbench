# 检索能力包与记忆设计（实现说明）

版本：0.3.2 · 日期：2026-10-15

## 三项检索技能

使用 `find-skills` 检查技能目录和 skills.sh / `npx skills find` 搜索结果后，没有发现能直接作为肿瘤心理支持、安宁疗护或量表临床判断核心依赖、且授权与临床质量均已验证的通用技能。因此 WB 采用三个随项目公开的 `SKILL.md` 流程模板，不安装第三方技能、不自动配置 DSH Agent、不伪造搜索工具权限：

1. `skills/clinical-guideline-search/SKILL.md`：指南、规范与共识。
2. `skills/clinical-evidence-search/SKILL.md`：原始文献、综述和临床试验。
3. `skills/palliative-care-search/SKILL.md`：疼痛、症状、姑息/安宁疗护框架。

它们作为可读的检索任务模板，由工作台写入用户当前 DSH 会话，或由 DSH 已启用的工具执行。现有 DSH 配置虽出现搜索扩展，但 `web` 工具未启用；因此界面不能承诺所有用户均可联网检索。不可用时要明确说明，不编造来源。KNOWS 为独立可配置的本地服务端连接，需按具体部署 API 协议验证。

## 记忆选择：用户目录下的结构化 JSON

实现中选择**用户明确选择目录里的 JSON 文件**，而不是 SQLite 或 IndexedDB：

- 数据少且以用户审核后的短文本、量表自述为主；直接 JSON 易于备份、人工检查、导出和迁移。
- DSH 已是会话正文的权威来源；不需要复制全文再构建第二份会话数据库。
- 插件服务端负责写本机文件，避开浏览器 IndexedDB 受 WebView profile 生命周期、目录迁移及导出管理影响的问题。
- JSON 不能高效全文检索或并发写入，因此将记录上限限制为 2,000；达到后提示用户导出/删除。

目录选择后写入 `cancer-psych-support-memory.json`，目前字段包括：

- `reviews`：用户确认认可后保存的角色 ID、会话 ID、时间、本次概要、用户原话、客观观察、下一步和鼓励收尾。
- `measurements`：量表标识/名称、用户自报分数、备注、用户填写的版本和会话 ID。
- `communicationPreferences`：用户主动填写的沟通偏好；可供后续新会话读取，不由模型自动推断。
- `knowledgeSources`：用户确认保存的标题、HTTPS 链接、来源机构、版本/日期和简短备注，不存整篇原文。
- `schemaVersion`：当前为 2；旧 schemaVersion 1 文件读取时提供空偏好/来源默认值，后续写入升级为 v2。

工作台不保存完整对话、搜索词、病历附件、患者身份信息或密码。沟通偏好与资料来源均显式由用户写入。删除/导出均在配置和相应列表操作。原生会话历史仍通过 DSH API 展示/恢复。

设置使用两个文件：

- `workbench-settings.json`：服务地址、检索路径、用户选择的数据目录。
- `workbench-secrets.json`：MinerU 与 KNOWS Key，权限受限，不返回给浏览器、不随工作台包、不进入模型上下文。

本地文件并非加密保险箱；当前同机具备用户文件权限的程序仍可读取。记录字段控制在必要范围内，密钥单独隔离写入，数据 API 仅由 DSH 本机授权连接访问。

## MinerU 与 KNOWS 范围

- MinerU：设置支持服务地址、密钥状态与移除密钥。0.3.2 尚未有上传/解析调用，页面明确提示不发送患者资料。后续需先做文件类型/大小限制、文件选择确认、删除识别信息提示、任务进度、超时/失败回退、源文件清理，再上线实际调用。
- KNOWS：用户配置基础 URL、API 路径与 Key。服务端仅使用 HTTPS（或 localhost HTTP），Bearer Key + JSON POST `{query, q}`。结果限制条数/长度，只展示 http(s) 源链接。不同部署可能需要适配请求/返回 schema；应提供 mock 集成测试和服务端联调记录。
- DSH web search：工作台提供三类去标识化任务提示，沿用宿主已启用工具；不创建工具、不静默发送。

## 临床心理安全

量表页暂以用途介绍和结果记录为主，不复制未经确认授权的题目，不自动评分或诊断。引入某一中文版本前，应逐项核验量表版本、语言效度、授权、筛查阈值解释及当地转介流程。安宁疗护检索强调舒适目标、疼痛/症状观察和与医疗团队沟通，不给药物剂量或调药指令。涉及即时危险优先现实世界急救/专业支持。

## 技能发现来源和局限

技能搜索目录（skills.sh）和 `npx skills find` 只用于发现候选模板，安装量不代表临床验证。曾检索 ToolUniverse 临床指南、文学检索/科学综述等社区项目，但它们涉及外部 MCP/运行时或面向研究编程环境，不能替代针对患者的质量、安全和授权审查，因此本项目不捆绑这些依赖。专业答案仍要求来源、版本/日期和适用地区，且明确对具体治疗决定的边界。
