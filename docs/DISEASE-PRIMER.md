## 0 本台的边界（先写在前面）

本台**不提供诊断与治疗方案**。`SPEC.md` §1 写的是：本产品不是心理治疗、医疗诊断、治疗决策或危机监护工具，不替代肿瘤团队、心理 / 精神卫生专业人员、社工和安宁疗护团队。因此本文件：

- 不写「你该怎么调整情绪」「哪种干预对你有效」；
- 不写药物名称、剂量与调整；
- 只整理**公开文件里列过哪些支持形式**，以及这些文件的版本状态。

## 1 定义（`definition`）

这里的「心理支持」指在肿瘤诊断、治疗、复发、安宁疗护与哀伤过程中，针对情绪与沟通问题的非药物性支持：倾听与情绪承接、把想说的话整理清楚、把担忧转成可以问临床团队的问题、在需要时转向专业人员。

- **两类东西要分开**：一是**支持形式**（心理教育、认知行为取向干预、支持性心理治疗、正念与放松练习、同伴支持、专业转介）；二是由专业人员做的**评估与处置**（含是否需要药物）——后者不在本台范围内。
- **自评量表只做登记**：Distress Thermometer、GAD-7、PHQ-9、ESAS-r 在本台只记「用过哪个工具、结果由用户自己填写」，不内嵌题目、不自动计分、不做分流判断（`SPEC.md` §4）。
- **不按病期分组**：心理支持与肿瘤分期没有一一对应关系，本台不把某种支持形式绑定到某个分期。

## 3 目前治疗全景概要（`landscape`）

心理支持不按「病期 / 线序」分组，这里按**指南与共识里出现过的支持形式**分组。只写「有这种形式」，不写怎么做、不写哪种更好。

### 3.1 面向患者本人的形式

- 心理教育：把疾病与治疗相关信息按患者能接受的方式讲清楚，减少信息缺口带来的不确定感；本台对应的是「把已知 / 未知整理出来」。
- 结构化心理干预（认知行为取向等）：由受训人员实施的短程干预，被列为可选形式之一；实施者与疗程属专业人员判断。
- 支持性心理治疗与陪伴：以倾听、情绪承接、意义与愿望表达为主，常见于安宁疗护情境。
- 正念与放松练习：作为辅助性自助形式被列出，不替代专业评估。

### 3.2 面向家属与照护者、以及关系层面的形式

- 同伴与家庭支持：病友群体、照护者支持、家庭沟通整理。
- 哀伤支持：面向失去亲人的照护者，不设阶段与时间表（本台 `bereavement-support` 角色同此口径）。

### 3.3 转介与升级

- 专业转介：出现持续情绪困扰、功能受损或风险信号时，转介心理 / 精神卫生专业人员、社工或安宁疗护团队。
- 药物相关处理：由临床专业人员评估决定，本台不涉及，也不记录具体药物。

**固定出口（原话照抄）**：

> 以上是文献与指南里列出的手段，按病期与线序排列，不代表任何一项适合你。选哪一个，这一句需要问你的医生。

## 7 本项目教训

- **「安慰」不是干预，也不是建议**。初稿在支持形式里写过「焦虑时可以试试深呼吸练习」，撤掉了：那既是从未核验过的做法，也是第 ③ 层的建议。改成「正念与放松练习被列为辅助性自助形式」，只说存在，不说做法。
- **量表「登记」不许滑成「筛查」**。写「用 DT 筛查出你有明显痛苦」是诊断口吻；本台只允许「用户自己填的分数与日期」。这条边界也决定 §3 不写任何阈值与切分点——授权版本没拿到，阈值不能凭印象写。
- 本段没有可引的指南版本号，趋势段按规范写「本台尚未整理」，**不为了凑满四段去编年份**。
