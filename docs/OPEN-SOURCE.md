# 开放源码与数据说明

本项目预期以开放源码方式维护，建议采用 MIT 许可证；在首次公开前由仓库维护者确认许可证文本、版权声明及第三方资源许可。角色名称、对话规则和界面素材应为原创或许可清晰。

## 数据边界

- `data/mock/` 仅为合成示例，无真实个人或患者资料。
- `assets/` 中两张暖色背景插画由用户提供；原图保留，JPG 优化图用于本地界面背景，不从外部图片站加载。`assets/characters/` 内六张原创 SVG 是可替换的人物占位图。
- `docs/ui-preview.html` 是独立交互预览，不连接 DSH，不发起模型请求；只验证页面选择、草稿和复制流程。
- 不提交 `.env`、令牌、模型密钥、真实会话导出、患者报告或本机路径。
- 用户自行配置 DSH 模型；插件不代理或储存模型凭证。
- 不将模拟数据包装成临床证据、疗效数据或已验证的心理干预。
- 不包含未授权的影视角色台词、剧照、宠物图片或长篇娱乐内容。
