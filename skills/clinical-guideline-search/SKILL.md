# 肿瘤指南与共识检索

1. 先确认国家/地区、癌种、治疗阶段和问题；只收集完成检索所需的最低信息。检索词不得包含姓名、医院号、联系方式或可识别病历片段。
2. 优先查 CACA、CSCO、ASCO、ESMO、NCCN、WHO 等原始发布方；记录完整标题、版本/日期、适用人群、地区和直接链接。
3. 区分正式指南、专家共识、患者教育材料和二手解读。不同来源意见不一致时并列说明，不制造统一结论。
4. 对临床建议说明“用于与医疗团队讨论”，不替个人诊断、选择方案、开立/停用药物或调整剂量。
5. 若当前 DSH 会话没有联网搜索工具，明确表示无法核实最新版本；不凭记忆补造网址、日期、指南推荐等级。
