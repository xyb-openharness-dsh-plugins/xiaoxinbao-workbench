# 肿瘤文献与临床研究检索

1. 明确问题、人群、干预/暴露、比较和结局；去掉所有可识别患者信息。
2. 优先原始论文、系统综述/Meta 分析、指南和 ClinicalTrials.gov、WHO ICTRP 等登记平台。
3. 对每条结果记录题名、作者/机构、年份、研究设计、研究人群、链接和重要限制；试验登记与已发表结果分开标识。
4. 不把观察性相关说成因果，不把早期阶段信号说成已证实获益，不预测个体效果或匹配治疗。
5. 结尾给出可带去肿瘤团队讨论的问题；当前检索工具不可用时直说无法检索。
